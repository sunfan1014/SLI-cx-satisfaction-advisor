# 十问自测表（快速定位·完整可填版）

> 本文件配合本专家正文使用。**这是本专家的"最快一档"入口**：用户想先花十几分钟自己摸一遍底、还不想填完整自检表，就用这一份。
> 完整六环自检表、四类能力自检表、成熟度自评表见 `diagnostic-tables.md`；术语速查见 `glossary-cheatsheet.md`。
> **十问不打分、不给题目逐题排名**，只回答一件事：**断在哪一环**。

---

## 一、什么时候用这张表

| 用户状态 | 用哪张 |
|---|---|
| "我想先自己摸一遍底，大概知道问题在哪" | **十问自测表**（本表，约 15 分钟） |
| "我要给团队做诊断／要按季度复评／要打印填表" | `diagnostic-tables.md` 六环自检表 |
| "我要知道哪个能力最弱、我们到几段位" | `diagnostic-tables.md` 四类能力表 ＋ 成熟度自评表 |
| "我完全报不出体量，也没专职岗" | 先用正文「小团队轻量六环」三问，本表作补充 |

**先定体量，再用表**：本表**不限组织规模**，任何体量都能答；但**读法随体量变**——

- **没有专职岗的（不论人数）**：答不上来多半不是能力问题，是"没人回头看"。**别急着补流程，先把最弱那环变成"每周有人看一眼"**。
- **100–1000 人（中型）**：答完先别铺开全套，**只补最弱的一环**，其余保持"有人、有动作"即可。
- **1000 人以上（大体系）**：本表第 9、10 题（口径、标准）在大体系里更容易暴露问题。**同一个满意度指标几个部门各给一个数**，答不上来是常态——先治口径与责任单元，别先上闭环工具。

---

## 二、怎么填

不用打分，不用准备材料，就一件事：**逐题问自己，答得上来就过，答不上来就在后面打个 ×。**

三条纪律：

1. **按事实答，不按印象答。** 能说出一个具体数字或一件具体事，才算答上来。
2. **只跟自己比。** 这张表不用于同行排名——跟别人比只会引发防御，跟自己比才有价值。
3. **结果自己留。** 它只用于内部判断，不必对外披露。

## 三、十问

| # | 问题 | 对应环节 | 答不出来意味着什么 | 你的答案 / × |
| - | -- | ---- | ---------- | ----- |
| 1 | 上个月走了多少客户？其中几个是「不高兴走的」？ | 发现 | 你只知道结果，不知道原因 | |
| 2 | 客户的不满信号有几种来源？主动采集的（评价、回访）占多少？ | 发现 | 你只在客户闹的时候才知道 | |
| 3 | 上个月客户不满，排前三的是哪三类？ | 定位 | 每次都从头查，经验攒不下来 | |
| 4 | 一个问题派给某个人之后，你怎么知道他处理了？ | 派单 | 派了等于没人管 | |
| 5 | 同一类问题，两个人的处理动作差在哪？ | 处理 | 服务标准靠个人经验，不统一 | |
| 6 | 处理完的问题里，有多少回头确认过客户真的满意？ | 验证 | 办完就当解决了 | |
| 7 | 同一类问题，三个月内重复发生的次数在降吗？ | 评估 | 你在重复付同一笔学费 | |
| 8 | 把那个最懂客户的人抽走一个月，这条线断在哪？ | 可接续性 | 你有的不是能力，是能人 | |
| 9 | 你最在意那个体验数，是谁在算、多久算一次、口径谁定？ | 口径 | 数字对不上是迟早的事 | |
| 10 | 新来的店长 / 顾问，靠什么知道「我们这儿服务该怎么做」？ | 标准 | 标准只在老人脑子里 | |

> **第 8–10 题是"延展题"**，不直接对应六环里的某一环——它们查的是**这条线能不能接续、能不能对得上、能不能传下去**。大体系里这三问更容易暴露口径与标准上的缺口。

## 四、怎么读结果

| 答不上来的数量 | 说明什么 | 建议 |
| ------- | ---- | --- |
| **0–2 问** | 链路基本是通的 | 先别花钱。把你答得最吃力的那一环盯三个月 |
| **3–5 问** | 这条链路上**一定有钱在漏**，只是你不知道漏在哪一环 | 值得走一遍。两个半天就能定位到具体断点 |
| **6 问以上** | 不是某一环的问题，是这条线**从来没被串起来过** | 回到答不上来的那几问，从对应环节里挑一个本周能做的动作 |

**一个规律**：十问里最常答不上来的不是第 1、2 问（发现），而是**第 6、7 问（验证和评估）**。

原因很实在——发现、派单、处理这三环每天都在发生，不做也会留下痕迹；而验证和评估，**没有专人盯就永远不会发生**。所以大多数企业的链路走到第四环就结束了：**问题处理完，等价于问题解决了。**

但它不等价。**没验证过的处理，你不知道它有没有真的解决；没评估过的改进，你不知道下次还会不会再犯。**

## 五、这张表只做到哪

十问帮你定位「断在哪一环」——**不打分、不给题目逐题排名**；结果区按未答数量分档，给的是处置强度。

要把现状量化到**六个维度、五个等级**（L1 被动响应 / L2 单点应用 / L3 流程贯通 / L4 数据驱动 / L5 智能原生），并排出下季度先动哪一维，走 `diagnostic-tables.md` 的**成熟度自评表**——**它在本专家范围内免费提供，不是另一个付费工具**，两者不是一回事：十问是"哪儿断了"，成熟度自评是"我们到哪一格、短板在哪"。

---

## 六、答完之后，两条路

**路一：自己改。** 挑你答不上来的那一环，改一个具体动作——不用加人、不用买东西。三个月后拿这十问再过一遍，看那一问答得上来没有。

**路二：往下做。** 按十问定位出的断点环，先自己排一个本周能做的动作；**若需要带一手数据与现场核证的深度诊断**（两个半天出一张纸，或团队级对齐），超出本技能范围。

> **一条纪律**：只填了表、没有真实数据可报时，**别急着找工具算数**——先把十问答得上来几问，跑出第一批事实，再谈参数与清单。判断层给的永远是"下一笔投入该花在哪"，不是"照这几步做就能提升多少"。
